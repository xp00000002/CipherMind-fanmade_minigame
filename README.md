CipherMind fanmade minigame是一个模仿Pigeon Games的多人解谜游戏《CipherMind》的游戏风格的非官方小游戏集。游戏代码使用AI辅助生成。

截至目前，本游戏集包含以下小游戏：
* **Chess(国际象棋)**
* Freecell(空当接龙)
* Klondike Solitaire(纸牌)
* Spider Solitaire(蜘蛛纸牌)
* **Compare(炸金花)**
* **Battle(斗地主)**
* *Turn Left*

**粗体**表示该小游戏使用了联机功能；*斜体*表示该小游戏为原创玩法。

本项目的小游戏在玩法上与《CipherMind》无相似或重合，部分素材使用了《CipherMind》素材的重绘版本，其余素材为自主设计。

`banks`文件夹储存了经过验证的Klondike Solitaire与Spider Solitaire双色难度的可解牌局；`turnleft-levels`文件夹储存了Turn Left的内置关卡。
